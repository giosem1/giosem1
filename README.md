### 🚀 Featured Projects

#### 🎓 Hypernegative – Bachelor Thesis Project
[![Hypernegative](https://img.shields.io/badge/-Hypernegative-333?style=flat&logo=github)](https://github.com/giosem1/hypernegative)  
**Hypernegative** is a Python library developed as my **Bachelor’s thesis** at the University of Salerno.  
It provides a **modular and reproducible framework** for **Hyperlink Prediction (HLP)** and **Negative Sampling (NS)** methods, designed for research and experimentation.  
**Tech stack:** Python, PyTorch, PyTorch Geometric (PyG)  
**Usage:** Can be used as a Python library or via CLI for evaluating HLP models.  

---

#### 🌐 WeCook – Social Media Platform for Recipes
[![WeCook](https://img.shields.io/badge/-WeCook-333?style=flat&logo=github)](https://github.com/giosem1/wecook)  
**WeCook** is a social media platform that allows users to share and discover recipes while connecting with other cooking enthusiasts.  
Users can personalize profiles, share recipes, engage with the community, and use advanced search and filtering options. Admins can monitor activity and manage reports.  
**Tech stack:** Angular, TypeScript, HTML, CSS (Frontend); Java, MySQL (Backend)  
Developed by a team of three students from the University of Salerno, with the goal of expanding it into a widely accessible platform for cooking enthusiasts.
